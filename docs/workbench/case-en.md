# Check the data before explaining the market

MarketData Sentinel helps Web3 product, operations and content colleagues verify a market-data figure before citing it. This local case uses a public Binance ETHUSDT historical sample for January 1, 2025, from 00:00 to 01:00 UTC. Three one-minute observations were deliberately removed from an isolated version. The exercise does not describe an actual exchange incident.

In the reproduced run, the incomplete version contained 57 of 60 expected candles and 6,933.4403 ETH in base-asset quantity. Replaying the registered raw input restored coverage to 60 of 60 candles and yielded 8,894.4444 ETH. The earlier version and its report remained available. These figures represent different data versions of the same window, not market growth or decline. ETH must not be relabelled as USD or USDT.

The workbench links rule-based findings to registered evidence and produces Chinese and English communication drafts, an issue brief and structured evidence. All displayed and exported figures come from the same validated report facts. Changed query parameters require a new report.

The restored version passed the implemented checks; this does not rule out every possible error or establish an economic cause. Editorial review and real-participant usability validation remain pending. No production deployment, user savings or commercial outcomes are claimed.
